# אליאניס — זיכרון במילים

אתר בעברית למשפחה ולקהל הרחב, שמאפשר להכיר את האדם ואת יצירתו דרך השירים שלו.

הפרויקט כולל מסך פתיחה, רשימת שירים עם תיאור קצר, נגן YouTube וחיפוש לפי שם או תיאור. אין הצגת מילות שירים. הסרטון הראשון, „מחרוזת פיגה”, נוסף לפי שם וקישור שמסר המשתמש. העמודים הנוספים עדיין בפיתוח.

## טכנולוגיות מתוכננות

React ו־TypeScript, עם Vite לפיתוח ובנייה ו־React Router לניווט. העיצוב יהיה מותאם לטלפון ולמחשב, מימין לשמאל, תוך שימוש ב־Flexbox.

React Router יתווסף בשלב בניית העמודים והניווט.

## הרצה

נדרש Node.js בגרסה 24 (גרסת הסביבה שנבדקה: 24.19.0).

```bash
npm ci --cache /workspace/.npm-cache
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

יש להריץ את הפקודות מתוך תיקיית הפרויקט. המטמון נמצא מחוץ למאגר כדי לא להסתמך על הרשאות כתיבה בתיקיית המשתמש בסביבת הענן.

## בדיקות

```bash
npm run build
npm run lint
```

הבנייה כוללת בדיקת TypeScript. בדיקת דפדפן מקומית בוצעה לרשימה ולחיפוש, לכתובת הנגן ולקישור הישיר; עדיין אין בפרויקט חבילת בדיקות דפדפן קבועה. ניגון הסרטון לא אומת: הגישה ל־YouTube מסביבת הענן נחסמה. יש לבדוק את הניגון בדפדפן עם גישה ל־YouTube; סרטונים שאינם מאפשרים הטמעה עשויים לדרוש צפייה בקישור הישיר.
