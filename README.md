# אליאניס — זיכרון במילים

אתר בעברית למשפחה ולקהל הרחב, שמאפשר להכיר את האדם ואת יצירתו דרך השירים שלו.

הפרויקט כולל דף בית, רשימת שירים עם חיפוש, עמוד לכל שיר עם תיאור קצר ונגן YouTube, ועמוד אודות עם תקציר סיפור החיים שמסר המשתמש. אין הצגת מילות שירים. שלוש המחרוזות נוספו לפי שמות וקישורים שמסר המשתמש; תמונות ופרטים נוספים על השירים עדיין ממתינים למידע מהמשפחה.

## טכנולוגיות מתוכננות

React ו־TypeScript, עם Vite לפיתוח ובנייה ו־React Router לניווט. העיצוב יהיה מותאם לטלפון ולמחשב, מימין לשמאל, תוך שימוש ב־Flexbox.

React Router מנהל את הניווט בין העמודים:

- `/` — דף הבית.
- `/songs` — רשימת השירים וחיפוש.
- `/songs/:songId` — עמוד שיר עם נגן וקישור ישיר ל־YouTube.
- `/about` — אודות האתר ומקום לסיפור האישי.

כתובת שאינה קיימת מציגה הודעה וקישור חזרה. בעת פריסה לשרת יש להגדיר החזרת `index.html` עבור נתיבי האתר, כדי שרענון עמוד פנימי יעבוד. Vite מטפל בכך בזמן פיתוח.

## מועדפים

אפשר לשמור שירים מהרשימה ומעמוד השיר ולסנן את הרשימה למועדפים בלבד. React Context משתף את הבחירה בין העמודים, ו־localStorage שומר אותה בדפדפן לאחר רענון. אין סנכרון בין מכשירים ואין צורך בחשבון. כשהאחסון חסום מוצגת הודעה והבחירה נשמרת רק בזיכרון עד לרענון.

## הרצה

נדרש Node.js בגרסה 24 (גרסת הסביבה שנבדקה: 24.19.0).

```bash
npm ci --cache /workspace/.npm-cache
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

יש להריץ את הפקודות מתוך תיקיית הפרויקט. המטמון נמצא מחוץ למאגר כדי לא להסתמך על הרשאות כתיבה בתיקיית המשתמש בסביבת הענן.

## בדיקות

```bash
npm run build
npm run lint
```

הבנייה כוללת בדיקת TypeScript. בדיקת דפדפן מקומית בוצעה לניווט, לרענון עמוד פנימי, לרשימה ולחיפוש, לכתובות שלושת הנגנים, לקישורים הישירים, למיקוד התוכן ולמצבי עמוד ושיר חסרים. נבדקו רוחבי 390 ו־1280 פיקסלים. עדיין אין בפרויקט חבילת בדיקות דפדפן קבועה. ניגון הסרטונים לא אומת: הגישה ל־YouTube מסביבת הענן נחסמה. יש לבדוק את הניגון בדפדפן עם גישה ל־YouTube; סרטונים שאינם מאפשרים הטמעה עשויים לדרוש צפייה בקישור הישיר.
