# אליאניס — זיכרון במילים

אתר הנצחה בעברית לזכרו של רבי אליהו (אליאניס) מזרחי ז״ל, למשפחה ולקהל שרוצה להכיר את שיריו ואת סיפורו.

## מה יש באתר

- בית עם שלוש מחרוזות וקישורים לסיפור החיים.
- רשימת שירים עם חיפוש בשם ובתיאור וסינון למועדפים.
- עמוד לכל שיר עם נגן YouTube, תיאור וקישור לצפייה ישירה.
- אודות עם תקציר שנערך מדברי המשפחה.
- חידון של חמש שאלות, משוב, ניקוד והתחלה מחדש.
- מועדפים שנשמרים בדפדפן, ללא חשבון וללא סנכרון בין מכשירים.
- עברית ו־RTL, תצוגה למסכים קטנים וניווט במקלדת.
- 11 תמונות מהקובץ שסיפקה המשפחה, משולבות בין חלקי הבית וסיפור החיים, עם כיתובים ותיאורי נגישות.

אין הצגת מילות שירים. התוכן נמסר בידי המשתמש; הביוגרפיה לא אומתה מול מקור חיצוני. אין מוני פעילות, תגובות או נתונים מדומים.

## טכנולוגיות

React, TypeScript במצב strict, React Router, Vite, CSS עם Flexbox ו־Context. בדיקות עם Playwright ו־axe-core.

נדרש Node.js בגרסה 24. נבדקו 24.19.0 בענן ו־24.21.0 להתקנה ולהרצה ראשונית במחשב Windows של המשתמש.

## הרצה ב־Windows

פתחו PowerShell בתיקייה שמכילה package.json:

```powershell
npm.cmd ci
npm.cmd run dev
```

פתחו בדפדפן את הכתובת שליד Local. השאירו את החלון פתוח. לעצירה: Ctrl+C.

לעדכון עותק ZIP: עצרו את השרת, הורידו ZIP חדש מ־GitHub וחלצו לתיקייה חדשה. פתחו בה PowerShell והריצו שוב את הפקודות. אם ערכתם קבצים בעותק הישן, שמרו אותם לפני החלפה. עדכון באמצעות Git אפשרי בעותק שנוצר באמצעות git clone.

## הרצה בענן

```bash
cd /workspace/ElianisZikaron-FinalProject
npm ci --cache /workspace/.npm-cache
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

המטמון נמצא מחוץ למאגר כדי לא להסתמך על הרשאות כתיבה בתיקיית המשתמש. שרת הענן אינו אתר ציבורי.

## בדיקות

```bash
npm run lint
npm run build
npm test
```

ב־Windows אפשר להשתמש ב־npm.cmd במקום npm. npm test בונה את האתר, מפעיל שרת preview זמני ומריץ 13 תרחישים בכל אחד משני הרוחבים: 1280 ו־390 פיקסלים, סך הכול 26 בדיקות. אין ניסיונות חוזרים אוטומטיים שמסתירים כשל.

דרוש Chromium. בענן מזוהה הדפדפן ב־/usr/bin/chromium. במחשב שאין בו דפדפן Playwright מותקן, התקינו פעם אחת:

```powershell
npx.cmd playwright install chromium
npm.cmd test
```

אפשר לבחור דפדפן מותקן באמצעות PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. דוח נוצר בתיקיית playwright-report; לפתיחה: npm run test:report. תוצאות ודוחות אינם נשמרים ב־Git.

הבדיקות מכסות ניווט, רענון, חיפוש, מועדפים, אחסון חסום ופגום, מקלדת וכתובות חסרות. axe בודק הפרות נגישות אוטומטיות לפי כללי WCAG A/AA נבחרים; זו אינה בדיקת נגישות מלאה. בקשות לנגן YouTube חסומות במכוון בבדיקות: כתובות וקישורים מאומתים, אך ניגון צריך לבדוק ידנית בדפדפן עם גישה לשירות.

## נתיבים ופריסה

- / — בית.
- /songs — שירים וחיפוש.
- /songs/:songId — צפייה והאזנה.
- /about — סיפור החיים.
- /quiz — חידון על חייו של אליאניס.

npm run build יוצר את dist. npm run preview מאפשר לבדוק את התוצר מקומית. באתר ציבורי צריך להחזיר index.html עבור כתובות פנימיות כדי שרענון יעבוד. התצורה הנוכחית מניחה פריסה בשורש הדומיין; תת־תיקייה דורשת התאמת base ו־basename. האתר טרם פורסם לציבור.

## שינוי התוכן

השירים נמצאים ב־src/data/songs.ts. לכל שיר מזהה קבוע וייחודי, שם, תיאור ומזהה סרטון. שימרו את המזהה כדי לא לשבור כתובות ומועדפים. סיפור החיים נמצא ב־src/pages/AboutPage.tsx. אין מסך ניהול או שרת.

תמונות המקור נשמרות ב־public/images ללא שינוי, והכיתובים והמידות ב־src/data/photos.ts. MemorialPhoto מציג את התמונה בשלמותה. למעט תמונת הפתיחה, התמונות משתמשות בטעינה עצלה. התמונות יחד הן כ־20.8 MB; גרסה ציבורית עם מגבלת תעבורה עשויה להפיק תועלת מעותקים דחוסים בהמשך. הקבצים המקוריים שהמשפחה סיפקה נשארו ללא עריכת תוכן.
