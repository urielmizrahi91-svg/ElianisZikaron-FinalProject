# התאמה לסילבוס והכנה להגשה

המיפוי מבוסס על הסילבוס שצורף. הוא מציין שרשימת הנושאים היא מפת דרכים ושיפורסמו הנחיות מפורטות למטלה בנפרד. המסמך אינו אישור של המרצה ואינו מחליף הנחיות אלה.

החלוקה והסרטון המוצגים בהמשך נשמרים מתוך המיפוי ההיסטורי. „הוראות של יריב.docx” אינו זמין בבדיקה הנוכחית; משקלי הציון, משך ההצגה וכללי ההגשה דורשים אימות מול ההוראות המקוריות.

## המוצר — 60%

| נושא | שימוש בפרויקט |
| --- | --- |
| HTML ו־CSS | מבנה סמנטי, עברית ו־RTL, צבעים, ריווח ועיצוב למסכים שונים |
| Flexbox | ניווט, כרטיסים ותוכן הכרטיס |
| JavaScript | אירועים, מערכים ואובייקטים, filter, map ו־find |
| TypeScript | Song, props ו־Context מטופסים ומצב strict |
| React | רכיבים, JSX, props, useState ו־useEffect |
| state משותף | Context למועדפים בין העמודים |
| ניתוב | React Router, נתיב דינמי לשיר ומצבי עמוד חסר |
| Master–Detail ו־API | רשימת שירים מקומית ופרטים לפי songId; רשימת שנים מקומית ופרטי המרה מ־Hebcal לפי year, עם Link ו־useParams |
| רשת ומצבי UI | fetch מתוך useEffect ב־MemorialDatePage, עם טעינה, שגיאה, הצלחה, ניסיון נוסף וביטול בקשה |
| בדיקות יחידה | 14 בדיקות Vitest, בדיקת טיפוסים ו־Vitest UI; npm test או npm run test, וממשק ב־npm run test:ui |
| בדיקות דפדפן | 48 בדיקות Playwright במחשב ובנייד עברו בתצורת הרצה זמנית; הפקודה הקבועה היא npm run test:e2e, בכפוף למגבלות ב־VALIDATION.md |
| מוצר עובד | חיפוש, מועדפים ועמודי צפייה; ניגון שלושת הסרטונים אומת לפי דיווח המשתמש במחשב Windows |

iframe אינו מימוש fetch או async/await; הדרישה נענית כעת בקוד המרת התאריכים באמצעות Hebcal. הרשימה עצמה מקומית, ולכן צריך לאמת מול ההנחיות אם נדרשת גם שליפת הרשימה מ־API. ההמרה אינה קביעה הלכתית של מועדי אזכרה. אין להוסיף classes או enums ללא צורך או דרישה מפורשת.

## הבנה — 20%

בסילבוס נדרש סרטון של כ־5 דקות ושאלון אישי. אלו פעולות של הסטודנט שלא בוצעו בידי הסוכן. צריך להסביר במילים שלך ולהיות מסוגל לשנות את הקוד.

תוכנית מוצעת לסרטון:

1. 0:00–0:40: קהל היעד והבחירה במוזיקה ובסיפור החיים.
2. 0:40–1:40: הדגמת חיפוש, נגן, אודות ומועדפים.
3. 1:40–2:30: App, React Router, Song וה־props של SongCard.
4. 2:30–3:30: useState, filter/map, Context ו־localStorage.
5. 3:30–4:20: commits, PRD ויומן AI.
6. 4:20–5:00: בדיקות ומגבלות, ושינוי קטן שאתה מבין, כגון תיאור שיר.

שאלות לתרגול:

- מה ההבדל בין props לבין state, ואיפה הם מופיעים?
- למה המועדפים נמצאים ב־Provider ולא בכל עמוד בנפרד?
- למה id משמש key במקום מספר סידורי?
- מה ההבדל בין Context ל־localStorage?
- מה קורה בחיפוש ללא תוצאות ובכתובת שיר חסרה?
- למה צריך fallback בשרת עבור רענון עמוד פנימי?
- מה הבדיקות מאמתות לגבי YouTube, ומה הן לא מאמתות?

## לפני ההגשה

- לבדוק את הנחיות המטלה המפורטות אם פורסמו.
- ניגון שלושת הסרטונים נבדק במחשב המשתמש ואושר בשיחה. יש לחזור על הבדיקה אם קישורי הסרטונים משתנים.
- להשלים העלאת השינויים האחרונים לאחר אישור.
- להקליט סרטון ולענות לשאלון לפי הנחיות המרצה.
- אם נדרש אתר ציבורי, לבחור שירות אירוח ולהגדיר ניתוב. האתר טרם פורסם לציבור.
