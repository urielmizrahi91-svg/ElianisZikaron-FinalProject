# בדיקות קבלה

## תוצאות אחרונות — Hebcal, Vitest ותיקון כותרת השירים

סיכום זה מבוסס על תוצאות הכלים בשיחת העבודה שהובילה ל־commits c1b2593, 6634df3 ו־2fe1332. אין זו הרצה חדשה במסגרת עריכת המסמכים. בדיקות הקבלה ההיסטוריות נשמרות בהמשך ומתייחסות לגרסאות ולסביבות דאז.

| בדיקה | תוצאה אחרונה מאומתת |
| --- | --- |
| npm run build | עבר לאחר מימוש התאריכים ולאחר חילוץ הלוגיקה לבדיקות |
| npm test וגם npm run test | 14 בדיקות יחידה עברו: 8 לחיפוש/סינון וקטלוג ו־6 לאימות נתוני תאריך; כולל בדיקת TypeScript של הבדיקות |
| npm run test:ui | הממשק אומת ב־Chrome והציג 14 הצלחות ואפס כישלונות; הפקודה משתמשת במצב watch |
| npm run lint | הסתיים בקוד יציאה 0 ללא אבחונים |
| Playwright | 50 בדיקות עברו: 25 תרחישים בכל אחד מרוחבי 1280 ו־390, עם Chrome מותקן ב־Windows; סיום ההרצה דרש עצירה ידנית של שרת preview, כמפורט להלן |
| fetch אמיתי מהאתר | הוצגו 22 באוקטובר 2025 לתשפ״ו ו־27 באוקטובר 2030 לתשצ״א; הבקשה יצאה מעמוד מקומי אל Hebcal והנתונים הוצגו באפליקציה |

בדיקות היחידה נמצאות ב־tests/unit/filterSongs.test.ts וב־tests/unit/convertedDate.test.ts. הן בודקות לוגיקה ללא רשת: חיפוש בתיאור ובכותרת, ניקוי רווחים, שילוב מועדפים, מזהים ייחודיים ודחיית תגובות/תאריכים לא תקינים. הן אינן מאמתות את ההתאמה המתמטית בין התאריך העברי ללועזי.

ארבעת תרחישי tests/memorial-dates.spec.ts בודקים רשימה ופרטים, Loading/Success, כשל וניסיון נוסף, תגובה לא תקינה ושנה שאינה נתמכת. תגובות Hebcal בהם מדומות. בדיקות הדפדפן הקיימות לשירים, מועדפים, גלריה וחידון נשארו ועברו. הנגנים החיצוניים חסומים במכוון בבדיקות, ולכן אין כאן אישור ניגון חדש של YouTube, Spotify או Amazon.

### תצורת הרצת Playwright בפועל

הרצת npm test הישנה, לפני שינוי הסקריפטים ל־Vitest, לא הסתיימה בהצלחה בסביבה. בניסיון עם Chrome מותקן גם נצפתה המתנה בסיום הרצה עם ניהול שרת אוטומטי. לבסוף הורץ שרת preview בנפרד ותצורת Playwright זמנית מחוץ למאגר: tests, שני גדלי החלון, שני workers, אפס retries, ו־executablePath של Chrome המותקן. שני קובצי ‎*.spec.ts הורצו ו־48 הבדיקות עברו. אין לייחס את ההצלחה הזאת להרצה מלאה של npm run test:e2e עם מנגנון ניהול השרת המקורי.

לאחר תיקון כותרת /songs/ ב־2fe1332 נוספה בדיקת רגרסיה אחת, המורצת בשני גדלי החלון: 21 תרחישים ב־tests/site.spec.ts ועוד 4 ב־tests/memorial-dates.spec.ts, כלומר 25 לכל רוחב ו־50 בסך הכול. הרגרסיה מכסה /songs וגם /songs/, רענון וכניסה לשיר וחזרה.

בהרצה העדכנית הופעלה npm run test:e2e -- --reporter=list בתצורת הפרויקט הרגילה, עם PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH שהצביע ל־Chrome המותקן, ללא קובץ תצורה זמני. כל 50 התרחישים דווחו כעוברים. הפקודה המתינה אחרי התרחיש האחרון; לאחר עצירת תהליך שרת ה־preview של ההרצה התקבל סיכום 50 passed וקוד יציאה 0. הסיבה להיתקעות בסיום לא הוכרעה, וסיום אוטומטי תקין עדיין טעון אימות בסביבת ההגשה. לא הותקן דפדפן נוסף. נתון 48 הבדיקות בפסקה הקודמת מתייחס להרצה ההיסטורית שלפני הרגרסיה ונשמר ככזה.

המרת Hebcal נבדקה בפועל דרך fetch מהאתר, מעבר לפתיחת כתובת API ישירות בשלב המחקר. בכך אומתה גישת CORS בסביבה שנבדקה בלבד; אין הבטחת זמינות עתידית. זהו converter בלבד, ללא קביעת אזכרה הלכתית או זמני שקיעה.

## תיעוד היסטורי

הסעיפים הבאים נשמרו כתיעוד מצב קודם. האמירה שבהם שהבדיקות האוטומטיות הורצו רק בענן אינה מתארת את ההרצות האחרונות ב־Windows. גם שם הפקודה npm test ומספרי הבדיקות משקפים את המצב ההיסטורי; כיום npm test מפעיל Vitest ו־npm run test:e2e מפעיל Playwright. מצב פרסום האתר, סרטון ההגשה והשאלון טעון אימות סופי ואינו מוכח מתוצאות בדיקה אלו.

## תוצאה — 7 באוקטובר 2026

לאחר הוספת החידון, בסביבת Linux עם Node.js 24.19.0 ו־Chromium, npm test סיים 26 בדיקות שעברו: 13 תרחישים ברוחב מחשב (1280) ו־13 ברוחב טלפון (390). הבדיקה בנתה את האתר עם TypeScript ו־Vite והשתמשה בשרת preview של תוצרי הבנייה. npm run lint עבר.

## מה אומת

- בית, עברית ו־RTL, שירים וקישור לביוגרפיה.
- חיפוש בשם ובתיאור, רווחים, ניקוי ומצב ללא תוצאות.
- שלושה עמודי שיר, כתובות נגנים וקישורים ישירים, רענון עמוד.
- ניווט פעיל, כותרת לשונית, מיקוד בתוכן וחזרה בדפדפן.
- עמוד ושיר חסרים עם קישורי חזרה.
- שמירת מועדף במקלדת, סינון משולב, שיתוף בין עמודים, רענון והסרה.
- אחסון פגום או חסום ומזהים לא קיימים או כפולים.
- דילוג לתוכן ותצוגה ללא גלילה אופקית בשני הרוחבים.
- סריקת axe-core לכללי WCAG A/AA נבחרים בארבעת העמודים, ללא הפרות שזוהו.
- טעינה תקינה של כל 11 התמונות, תיאורים נגישים ושמירת יחס המידות בשני רוחבי המסך.

רוחב טלפון הוא הדמיית גודל חלון ב־Chromium ולא בדיקה במכשיר אמיתי. axe אינו בדיקת נגישות מלאה ולא כולל את תוכן הנגן החיצוני.

## בדיקת YouTube במחשב המשתמש

בקשות הווידאו חסומות במכוון בבדיקות; נבדקים קישורים וכתובות ולא ניגון. בסביבת הענן בקשת מידע מ־YouTube נחסמה ב־403. במחשב המשתמש יש:

1. לפתוח את רשימת השירים ולבחור כל מחרוזת.
2. לוודא שהסרטון מתאים לשם ולהפעיל אותו.
3. לבדוק תמונה, קול ומסך מלא.
4. לבדוק את הקישור הישיר.
5. אם ההטמעה אינה מותרת, להשתמש בקישור הישיר או לבחור קישור אחר באישור המשתמש.

ב־7 באוקטובר 2026 המשתמש התקין והפעיל את הגרסה המעודכנת מתוך VS Code במחשב Windows. הוא אישר ניגון של „מחרוזת פיגה”, תמונה וקול ב„מחרוזת בומפם, אוסקסיזים”, ולאחר בדיקת המחרוזת השלישית אישר שהכול תקין. ניגון שלושת הסרטונים: **אומת ידנית לפי דיווח המשתמש**. מסך מלא ופתיחת הקישור הישיר לא דווחו בנפרד ולכן אינם מסומנים כבדיקות שעברו.

## בדיקת מועדפים במחשב המשתמש

המשתמש התבקש לשמור את פיגה במועדפים, לסנן ולרענן. תחילה דיווח שהשיר לא מופיע, ולאחר בירור הסינון אישר שהמצב הסתדר. לא נדרש שינוי קוד. זהו אישור ידני של המשתמש שהבדיקה הסתיימה בהצלחה; בדיקת ההתמדה אחרי רענון כוסתה גם בחבילת Playwright בענן.

## מגבלות אחרות

- סיפור החיים מבוסס על דברי המשפחה, ללא אימות חיצוני.
- התקנה והרצת הגרסה המעודכנת בוצעו במחשב Windows של המשתמש. חבילת הבדיקות האוטומטית הורצה בענן ולא במחשבו.
- האתר טרם פורסם לשירות אירוח ציבורי.
- תיעוד הקורס הוכן; סרטון ההגשה והשאלון לא הושלמו.

חידון: נבדקו ניקוד מלא וחלקי, נעילת תשובה, משוב, ניווט במקלדת ואיפוס סבב. עמוד /quiz נכלל גם בבדיקות הנגישות והתאמת הרוחב.

## עיצוב בהשראת Apple

נבדקו ניגודיות הכיתובים באזורים הכהים, תצוגה במחשב ובטלפון והופעת התמונות בשלמותן. בדיקה ידנית ב־Chromium אימתה שהעדפת reduced motion מבטלת את האנימציה ושבלי IntersectionObserver התוכן נשאר גלוי. מיקוד ראשוני נשאר בדפדפן כדי ש־Tab ראשון יגיע לקישור הדילוג; מעבר בין עמודים ממשיך למקד את התוכן.
