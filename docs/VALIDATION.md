# בדיקות קבלה

## תוצאה — 7 באוקטובר 2026

לאחר שילוב התמונות, בסביבת Linux עם Node.js 24.19.0 ו־Chromium, npm test סיים 22 בדיקות שעברו: 11 תרחישים ברוחב מחשב (1280) ו־11 ברוחב טלפון (390). הבדיקה בנתה את האתר עם TypeScript ו־Vite והשתמשה בשרת preview של תוצרי הבנייה. npm run lint עבר.

## מה אומת

- בית, עברית ו־RTL, שירים וקישור לביוגרפיה.
- חיפוש בשם ובתיאור, רווחים, ניקוי ומצב ללא תוצאות.
- שלושה עמודי שיר, כתובות נגנים וקישורים ישירים, רענון עמוד.
- ניווט פעיל, כותרת לשונית, מיקוד בתוכן וחזרה בדפדפן.
- עמוד ושיר חסרים עם קישורי חזרה.
- שמירת מועדף במקלדת, סינון משולב, שיתוף בין עמודים, רענון והסרה.
- אחסון פגום או חסום ומזהים לא קיימים או כפולים.
- דילוג לתוכן ותצוגה ללא גלילה אופקית בשני הרוחבים.
- סריקת axe-core לכללי WCAG A/AA נבחרים בארבעת העמודים, ללא הפרות שזוהו.
- טעינה תקינה של כל 11 התמונות, תיאורים נגישים ושמירת יחס המידות בשני רוחבי המסך.

רוחב טלפון הוא הדמיית גודל חלון ב־Chromium ולא בדיקה במכשיר אמיתי. axe אינו בדיקת נגישות מלאה ולא כולל את תוכן הנגן החיצוני.

## בדיקת YouTube במחשב המשתמש

בקשות הווידאו חסומות במכוון בבדיקות; נבדקים קישורים וכתובות ולא ניגון. בסביבת הענן בקשת מידע מ־YouTube נחסמה ב־403. במחשב המשתמש יש:

1. לפתוח את רשימת השירים ולבחור כל מחרוזת.
2. לוודא שהסרטון מתאים לשם ולהפעיל אותו.
3. לבדוק תמונה, קול ומסך מלא.
4. לבדוק את הקישור הישיר.
5. אם ההטמעה אינה מותרת, להשתמש בקישור הישיר או לבחור קישור אחר באישור המשתמש.

ב־7 באוקטובר 2026 המשתמש התקין והפעיל את הגרסה המעודכנת מתוך VS Code במחשב Windows. הוא אישר ניגון של „מחרוזת פיגה”, תמונה וקול ב„מחרוזת בומפם, אוסקסיזים”, ולאחר בדיקת המחרוזת השלישית אישר שהכול תקין. ניגון שלושת הסרטונים: **אומת ידנית לפי דיווח המשתמש**. מסך מלא ופתיחת הקישור הישיר לא דווחו בנפרד ולכן אינם מסומנים כבדיקות שעברו.

## בדיקת מועדפים במחשב המשתמש

המשתמש התבקש לשמור את פיגה במועדפים, לסנן ולרענן. תחילה דיווח שהשיר לא מופיע, ולאחר בירור הסינון אישר שהמצב הסתדר. לא נדרש שינוי קוד. זהו אישור ידני של המשתמש שהבדיקה הסתיימה בהצלחה; בדיקת ההתמדה אחרי רענון כוסתה גם בחבילת Playwright בענן.

## מגבלות אחרות

- סיפור החיים מבוסס על דברי המשפחה, ללא אימות חיצוני.
- התקנה והרצת הגרסה המעודכנת בוצעו במחשב Windows של המשתמש. חבילת הבדיקות האוטומטית הורצה בענן ולא במחשבו.
- האתר טרם פורסם לשירות אירוח ציבורי.
- תיעוד הקורס הוכן; סרטון ההגשה והשאלון לא הושלמו.
